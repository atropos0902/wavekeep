# Detector versions aren't edited

Version 2 scored badly on the first labeled set: 91.6% precision and 78.4% recall, because it asked for proof that an employer was meant and the proof was often missing. Editing it would have changed the numbers behind any report approved under it, so the fix is version 3.

Version 3 turns the question round. A capital letter in mid sentence is taken as a name unless something says otherwise. On the set it was tuned on it scores 99.0% and 97.9%. On a second set written afterwards, with other names and sentences and scored once, it gets 97.5% and 79.8%. The second pair is the one to believe.

Of the 40 misses in the second set, 25 are spellings nobody had entered as a name ("O'Brien and Daughters" for "O'Brien & Daughters"), and the names screen is where those go. The other 15 are an everyday word opening a sentence, standing alone, or in quotes. Version 4 should start there and needs a third set.
