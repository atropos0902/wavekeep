# A verdict needs the test and the interval

The sign-flip test and the interval are two calculations and they disagree near the edge. The page says "Up" or "Down" only when the test is under 5% and the interval excludes zero. That costs a little power and means nobody sees "Up" beside an interval that crosses zero. They can still see an interval that excludes zero beside "Can't tell", and that's the intended direction to be wrong in.

The overview makes fifteen comparisons at once and doesn't correct for it. A lone "Up" among fifteen is weak. The compare screen prints the p value so a careful reader can discount it.
